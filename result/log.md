## main-net
1. net1: 
    - 主要改动：baseline1 基础上，采用新模型架构
    ```markdown
    历史观测 [B, 705]
        │
        │ reshape，按最旧帧 → 最新帧排列
        ▼
    帧序列 [B, 15, 47]
        │
        │ 共享帧编码器
        │ Linear(47,128) + LayerNorm
        ▼
    帧特征 [B, 15, 128]
        │
        │ 加可学习位置编码 [1,15,128]
        ▼
    2 × Pre-LN Transformer Block
        │
        ├─ 4-head Self-Attention
        ├─ FFN：128 → 512 → 128
        ├─ 两处残差连接
        └─ Dropout = 0
        │
        ├─ 最新时序特征 x[:, -1, :]          [B,128]
        └─ 最新原始帧特征 embedding[:, -1, :] [B,128]
                            │
                            ▼
                        拼接 [B,256]
                            │
                            ▼
                动作头：256 → 256 → 128 → 12
                            │
                            ▼
                    12维动作均值
    ```
    - 模型：net1.onnx
    - 表现：
        - 站立时存在轻微前进
        - 前进有向左偏航问题，后退很慢
        - 左移存在朝向右偏问题，右移较慢
        - 左转右转正常
        - 腿部存在外摆问题，且抬腿幅度较小
